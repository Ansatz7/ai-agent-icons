# AI 头像集

15 款 AI 相关角色的非官方拟人头像，以及用于对照的品牌原标识。

[在线浏览](https://icons.ansatz-vector.com/)

## 文件

```text
avatars/
  png/{尺寸}/{角色}.png
  ico/{角色}.ico
brand-marks/
  {角色}.png 或 {角色}.svg
  sources.json
```

- PNG：16、32、48、64、128、256、512、1024 px，共 8 档尺寸。
- ICO：每个文件内含 16、32、48、64、128、256 px 六档尺寸。
- PNG 和 ICO 均为现有原文件，原样复制，未进行有损压缩或降低画质。
- 整套包和 512 px 精简包通过本仓库的 Releases 下载，不重复存入源码目录。
- 原标识来源见 [brand-marks/sources.json](brand-marks/sources.json)。
